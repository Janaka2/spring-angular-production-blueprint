# Code excerpts

These files are copied from the private AssetCare codebase to show how it is written. They are about 10 of roughly 160
source files.

They are deliberately incomplete: the core domain and use-case files show signatures and contracts only, with the bodies left out. They are not a buildable project and are not meant to be one. The build files,
persistence adapters, REST controllers, database migrations, security configuration, deployment, pipelines and most of
the tests stay private.
